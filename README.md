# Капитал — инвестиции простыми словами

Адаптивное учебное веб-приложение для iPhone, Android и компьютера. Работает без сборки и без внешних библиотек.

## Что внутри

- 134 понятия в 8 тематических разделах;
- для каждого термина — простое определение, пример и практический нюанс для банка;
- поиск по словам и описаниям, фильтры по категориям;
- избранное, отметка «Изучено», персональный прогресс;
- тест из 10 вопросов и карточки для повторения;
- светлая и тёмная темы;
- офлайн-режим после первого открытия на HTTPS (PWA).

## Как открыть

Просто откройте `index.html` в браузере компьютера. Для проверки с телефона лучше опубликовать папку через GitHub Pages.

## Как опубликовать на GitHub Pages

1. Создайте публичный репозиторий (либо используйте существующий, если Pages доступен).
2. Загрузите **содержимое** этой папки в корень репозитория (`index.html`, `sw.js`, `manifest.webmanifest`, иконки).
3. В Settings → Pages → Build and deployment выберите Deploy from a branch, ветку `main`, каталог `/ (root)`.
4. Откройте адрес, который выдаст GitHub Pages, на iPhone в Safari.
5. Нажмите «Поделиться» → «На экран Домой». Приложение запустится почти как обычное iOS-приложение.

Прогресс и избранное хранятся в localStorage браузера и не синхронизируются между устройствами. Открытие `index.html` напрямую на iPhone из приложения «Файлы» может работать с ограничениями; используйте GitHub Pages.

## Источники и ограничения

В приложении указаны ссылки на официальные разъяснения Банка России. Это образовательный материал; проверяйте актуальное регулирование и условия конкретных продуктов. Код и учебные данные можно редактировать без фреймворков. Версия 1.0.
